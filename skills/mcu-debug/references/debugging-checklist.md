# MCU 外设调试检查清单

## 新板子/新硬件上电异常排查顺序

### 1. 物理连接检查（排线/杜邦线）
- 排线母座是否有 1 脚标记？插反可能导致信号错位
- 测量排线两端对应引脚是否导通
- 排线是否完全插入锁紧

### 2. 电源测量
- 各电源轨电压是否正确（3V3, 5V, VM 等）
- 编码器 VCC：必须 3.3V 不可 5V（否则信号尖峰导致重启）
- MCU 供电引脚与 GND 之间电压是否稳定

### 3. 信号引脚测量
- 用示波器量 PWM 引脚实际电平（不要只看代码）
- I2C SCL/SDA 引脚是否被特殊功能占用（BLS/bootloader 等）
- 方向引脚电平是否正确

### 4. 原理图对照
- 怀疑某个引脚时，查原理图确认该引脚是否有其他功能复用
- 特别留意：BLS、BOOT、RST 等特殊功能引脚

## 常见症状 → 原因映射

| 症状 | 优先排查 |
|------|---------|
| 上电飞车/电机全速转 | 排线插反、方向引脚错位、PWM CC=0 误配置 |
| 单片机频繁重启 | 编码器供电过高(5V)、电源纹波、IO 口电压尖峰 |
| I2C 不工作 | 引脚被特殊功能占用(BLS)、上拉电阻、引脚分配错误 |
| UART 丢数据 | 步进电机干扰、共地问题、波特率偏差 |
| 现象不固定/时好时坏 | 接触不良、排线松动、焊接虚焊 |
| 换了杜邦线就好了 | PCB 走线寄生参数问题（过冲/振铃） |

## 排查原则

1. **先硬件，后软件** — 不要第一时间怀疑代码写错
2. **先万用表，后示波器** — 先量通断和电压，再看波形
3. **最小系统法** — 拔掉非必要外设逐步缩小范围
4. **对比实验** — 杜邦线 vs PCB、旧板 vs 新板
5. **读寄存器** — 绕过抽象层，直接读硬件寄存器确认配置生效
