# 论文检索与批判性阅读

目标：不只是"找到论文"，而是回答——这个场景难点在哪、前人做了什么、缺什么、我的方法能不能补、怎么补、预期效果、当前与目标的差距。

## 流程（按序执行）

### 1. 定题（先想清楚再搜）

- 读立论 SSOT：`traffic_rl_project/docs/RESEARCH_POSITIONING.md` §1.3/§1.5/§1.6，明确当前检索服务于哪个论点/缺口（真空白 = "多列群组 × 车钩力 × MARL"，勿拿已知结论当待定重查）。
- 把用户的模糊请求收敛成 1-3 个具体检索问题（例："长大下坡循环制动 RL 是否考虑车钩力"）。

### 2. 网络检索（第一通道）

- 用 WebSearch / scholar-search MCP（Semantic Scholar + arXiv 双通道）按检索问题搜。
- 关键词中英都搜；先广后深：综述/近 3 年 → 定向精读。
- 每篇先看标题+摘要筛选，只有过了"四块精读"门槛的才进入分析。

### 3. 本地文献库检索（第二通道，必做）

- 入口：`traffic_rl_project/docs/papers/README.md`（86 个文件，5 个主题子目录清单）。
- 命中后直接读：PDF / 同名 `.md` 信息卡（数据 SSOT）/ `*_fulltext.txt`（可 Grep）。
- 技术点→论文反查：`traffic_rl_project/docs/REFERENCE_INDEX.md`。
- **检索无命中 ≠ 不存在**：Grep 未命中时用 Glob/LS 列子目录确认再下结论。

### 4. 四块精读（每篇入选论文必读）

1. **摘要**：问题、方法、结果一句话。
2. **引言**：它认定的场景难点是什么、它批评前人什么。
3. **结论**：它承认的局限、claim 的边界。
4. **对比实验设计**：基线是谁、指标是什么（是否含车钩力、口径是否断面力 ADR-018）、场景/坡道/编组是什么、样本量与随机性。

### 5. 批判性七问（每篇一张卡片，逐条答）

| # | 问题 | 答题要求 |
|---|------|---------|
| 1 | 场景难点在哪 | 论文针对什么场景，难点的物理/工程本质 |
| 2 | 前人做了哪些工作 | 引言+related work 里的做法分类（可引本项目文献清单佐证） |
| 3 | 有哪些缺陷 | 前人（及本文）的明确局限；**只写文献明写的，推断必须标注为推断** |
| 4 | 我的方法能否解决缺陷 | 对照本项目立论（车钩力显式建模 + 多列群组 + MARL 机车级 ED/AB + 安全层），能/不能/部分能 |
| 5 | 应该如何解决 | 具体机制：用本项目的哪个设计对应哪条缺陷（一一对应，不空谈） |
| 6 | 预期效果 | 补上缺陷后预期在哪些指标上改善（车钩力 ≤1000kN、列距、速度带一致、免重辨识成本） |
| 7 | 现在和目标的差距 | 已有证据 vs 还缺的实验/文献/验证，列出 gap 清单 |

### 6. 输出格式

- **逐篇卡片**：引用信息（作者/年份/venue/DOI 或"待核"）+ 七问回答。
- **汇总表**：论文 × 是否含车钩力 × 单列/多列 × 方法 × 对比基线 × 可借鉴点。
- **差距清单**：gap → 需要补的实验或文献，按优先级排。
- 语言：结论直白，不用 Regime A/strawman 类模糊代号；区分"文献明写"与"我的推断"。

## 纪律（硬约束）

- **一手优先**：筛选用二手可以，下结论必须回一手（PDF/摘要原文）；索引记录不得当终结论。
- **勿推广**：只能说"Zhang2024/Liu2021/Wang2025 这些单列车钩力未入模"，禁止写成"文献都忽略车钩力"（Wang2026、Song2026 已含）。
- **对比实验公允性**：评他人对比设计时，按本项目标准核——物理模型两侧同源、基线是否被公平标定（对照 ADR-016/022 口径）。
- **新文献落地**（用户要求保存时才做）：文件进对应主题子目录 `作者年份_主题.pdf` → 登记 `docs/papers/README.md` → 被正文引用则三处同步（README + `REFERENCE_INDEX.md` + `refs.bib`）。
- 临时检索脚本用后即删；不改任何 SSOT/ADR。
